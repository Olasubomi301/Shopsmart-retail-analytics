# ShopSmart Retail Analytics Project

## 1. Project Overview

This project was completed as part of the AnalystLab Africa Experience Lab Internship Programme, Week 1: Mission 01 — Retail Sales Analysis with Microsoft Excel.

The project focuses on analysing the sales and operational data of ShopSmart Retail Ltd, a retail business operating across multiple stores in Nigeria. The analysis aims to help management understand sales performance, customer behaviour, product returns, and inventory levels to support informed business decisions.

## 2. Project Objectives

The objectives of this project were to:

- Understand and prepare the supplied retail datasets for analysis.
- Clean, organise, and format data using Microsoft Excel and Power Query.
- Apply lookup functions to combine relevant information from different datasets.
- Analyse sales performance by month, store, product, category, brand, state, and customer demographics.
- Identify top-performing products, customers, stores, and regions.
- Examine product returns and inventory levels.
- Develop an executive dashboard and provide actionable business recommendations.

## 3. Data Sources

The analysis used nine datasets supplied for the ShopSmart Retail Analytics assignment:

1. Customers
2. Products
3. Orders
4. Stores
5. Returns
6. Employees
7. Suppliers
8. Inventory
9. Order_Items

The datasets contain information about customers, products, transactions, store locations, returns, employees, suppliers, and stock levels.

## 4. Methodology and Tools

Microsoft Excel was used as the primary analysis tool. The following techniques were applied:

- **Data preparation:** Imported, inspected, cleaned, and formatted the datasets using Excel and Power Query.
- **Data organisation:** Converted datasets into Excel Tables and checked for duplicate records, missing values, and data inconsistencies.
- **Data integration:** Used lookup functions, including XLOOKUP, to retrieve related information from different tables.
- **Data analysis:** Used Excel formulas and PivotTables to calculate key performance indicators and analyse sales, customer, product, regional, and inventory performance.
- **Data visualisation:** Created PivotCharts to present the findings clearly.
- **Dashboard development:** Designed an executive dashboard to summarise key metrics and visual insights.
- **Business reporting:** Prepared findings and recommendations to support management decision-making.

## 5. Key Findings

The analysis identified the Beauty category as the highest-revenue category in the reported category analysis. ShopSmart Lagos was identified as the best-performing store, while the South region recorded the highest reported regional revenue. May was identified as the highest-revenue month in the monthly analysis.

The analysis also highlighted customers with the highest spending, a leading supplier, stores requiring inventory attention, and the need to investigate product returns, particularly within the Beauty category.

## 7. Conclusion

This project demonstrates the application of Microsoft Excel to retail data analysis, from data preparation and integration to reporting and visualisation. The findings provide a basis for improving inventory management, reducing avoidable product returns, strengthening sales performance, and supporting data-driven business decisions at ShopSmart Retail Ltd.
